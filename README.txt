ALFAKHRANI — موقع تحميل الفيديوهات

التشغيل:
1. ثبّت Node.js 18+.
2. ثبّت yt-dlp على السيرفر من https://github.com/yt-dlp/yt-dlp#installation
3. افتح Terminal داخل مجلد المشروع وشغّل: npm start
4. افتح http://localhost:3000

المشروع فيه صفحتان: التحميل والسجل. السجل محفوظ في المتصفح على الجهاز نفسه.
وظيفة التحميل الفعلية تحتاج سيرفر يدعم Node.js وتثبيت yt-dlp؛ ملفات الواجهة وحدها لا تكفي للاستضافة الثابتة.
يدعم الفيديوهات العامة التي تسمح المنصة بتنزيلها، ولا يتجاوز المحتوى الخاص أو تسجيل الدخول أو DRM. لا تستخدمه لانتهاك حقوق النشر أو شروط المنصات. بعض المواقع قد لا تعمل أو تتغير طريقة دعمها.
حد حجم الملف الحالي 500MB والمهلة 3 دقائق.

نشر على Render من الموبايل (باستخدام Docker):
1) فك ضغط ZIP على جهازك إن أمكن، أو نزّل الملف إلى الهاتف.
2) أنشئ مستودع GitHub جديدًا من github.com.
3) ارفع محتويات المجلد إلى المستودع، مع إبقاء Dockerfile في جذر المستودع (لا ترفع ملف ZIP وحده).
4) في render.com افتح Dashboard > New + > Web Service، واربط مستودع GitHub.
5) اختر Language/Runtime = Docker، ثم Create Web Service.
6) انتظر انتهاء Build/Deploy. سيظهر رابط onrender.com عند نجاح النشر.

ملاحظة: بعض قيود المنصات/الاستضافة قد تمنع التنزيل أو تتطلب تحديث yt-dlp. اختبر فقط بروابط عامة مسموح بتنزيلها.
